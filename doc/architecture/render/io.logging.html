Prompt

A console interface for the user to query state and issue commands.

CommandParser

Loads a sequence of commands from a structured file (e.g., JSON). Each command indicates a delay since the last command, an action to take, and an optional tag string. Commands simulate manual oversight and administration of the factory and are routed to static singletons (e.g., actor.Directory.instance()._____()).
